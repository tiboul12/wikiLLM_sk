# TEST-022 : Les cascades du volet se replient

**Préalable** : Section Réception ou Projet.

**Étapes** :

1. Cliquer le triangle d'un nœud qui a des enfants.
2. Cliquer ⊟ puis ⊞.

**Attendu** : Le nœud se replie et se déplie ; ⊟/⊞ replie ou déplie tout ; la page Cascade n'existe plus.

**Automatisation** : headless (lot 2).
