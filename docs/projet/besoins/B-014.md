# B-014 : Suivre chaque exigence jusqu'à l'idée qui l'a fait naître

**Qui** : Tibo, l'agent, plus tard l'équipe.

**Besoin** : Savoir d'où vient une exigence (storyboard, analyse, idée, pitch) et ce qu'elle est devenue (code).

**Pourquoi** : Le principe d'identifiants et de sources du framework (I.D.E.A., B.I.L.A.N.) se perd dans le chat.
