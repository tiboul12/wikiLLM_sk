# B-004 : Relier décisions et exigences au code qui les applique

**Qui** : Tibo, l'agent, la future équipe.
**Besoin** : Partir d'un ADR ou d'une exigence et trouver le code concerné, et inversement.
**Pourquoi** : Les ADR ne pointent vers aucun code ; aucune exigence n'est identifiée.
