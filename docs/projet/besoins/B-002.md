# B-002 : Savoir ce qu'une modification va toucher avant de la faire

**Qui** : L'agent de code.
**Besoin** : Connaître les appelants d'une fonction et les décisions et exigences qui la concernent.
**Pourquoi** : Aucun outil actuel ne calcule les appelants ; les régressions se découvrent après coup.
