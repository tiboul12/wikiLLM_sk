# B-025 : Suivre un projet version par version

**Qui** : Tibo, qui définit le besoin, relit, réceptionne et fait développer son projet par un agent.

**Besoin** : Voir d'un seul tenant tout ce qui constitue une version (demande, analyse, définition, cahier des charges, besoins, exigences, tests, décisions) et où en est chaque document.

**Pourquoi** : REC-083, 090, 101.2, 103, 114 (BDR-v9-1).
