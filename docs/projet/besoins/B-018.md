# B-018 : Régler l'IA de wikik et piloter l'agent de développement depuis le projet

**Qui** : Tibo, qui fait développer son projet par un agent (Claude Code) et le réceptionne dans wikik.

**Besoin** : Choisir l'IA que wikik utilise, reprendre ses consignes, et envoyer le traitement d'une réception à l'agent sans changer de fenêtre.

**Pourquoi** : REC-019, REC-022, REC-041 (BDR-v7-1).
