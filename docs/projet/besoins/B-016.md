# B-016 : Retrouver le code d'un écran à partir d'une remarque

**Qui** : l'agent de code, et Tibo quand il relit.

**Besoin** : Une remarque désigne l'écran par son code (composant, fichier) et par les exigences qui le concernent.

**Pourquoi** : sans ce lien, l'agent cherche le code à partir d'un nom d'écran ; la carte des pages est aussi à recopier pour chaque projet (BDR-v5-1).
