# B-001 : Comprendre la structure d'un projet sans relire ses fichiers source

**Qui** : L'agent de code (et Tibo).
**Besoin** : Obtenir le rôle des modules, fichiers et fonctions d'un projet sans ouvrir le code.
**Pourquoi** : Chaque session relit des fichiers entiers ou une cartographie complète (`code-map.md`, 214 lignes ; `app.rs` d'ATS, 2 521 lignes).
