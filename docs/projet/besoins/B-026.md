# B-026 : Régler les agents là où on s'en sert

**Besoin** : Une connexion au LLM réglée une fois, et les consignes propres à une tâche accessibles sur la page où l'agent intervient.

**Pourquoi** : REC-062, 104.3, 105, 106, 107 (BDR-v9-1).
