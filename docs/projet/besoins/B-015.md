# B-015 : Faire ses retours d'utilisateur de façon ordonnée, page par page

**Qui** : Tibo, qui reçoit une application (la sienne ou celle d'un projet).

**Besoin** : Voir toutes les pages de l'application, y déposer une remarque par carte avec ses captures, puis repasser sur l'ensemble pour décider de chaque remarque.

**Pourquoi** : les retours arrivent aujourd'hui en vrac dans la conversation, sans liste des écrans ni lieu pour les images (BDR-v5-1).
