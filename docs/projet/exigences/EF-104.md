# EF-104 : Appeler le LLM par le CLI local, branché sur wikik

**Énoncé** : Le fournisseur par défaut lance `claude -p` avec le serveur MCP de wikik (outils en lecture seule) et un schéma JSON ; il est configurable dans `wikik.toml` ; un fournisseur factice sert aux tests.

**Critère d'acceptation** : Avec le fournisseur factice, une étape complète se joue sans réseau ; avec `claude`, la réponse respecte le schéma de la fiche.
