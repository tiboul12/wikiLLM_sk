# EF-025 : Requête cherche

**Énoncé** : `wikik query cherche <texte>` renvoie les symboles et documents dont la doc contient le texte (recherche plein texte), avec leur voisinage immédiat.

**Critère d'acceptation** : Chercher un mot présent dans un seul bloc renvoie ce symbole en premier.
