# ENF-005 : Distribution en un seul binaire

**Énoncé** : L'outil est un exécutable unique, sans dépendance à installer, pour Linux en v1.
**Critère d'acceptation** : `cargo build --release` produit un binaire qui fonctionne sur une machine sans Rust ni Node.
