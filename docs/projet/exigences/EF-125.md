# EF-125 : Donner les remarques à l'agent de code

**Énoncé** : Un outil MCP doit lister les remarques ouvertes (texte, page, symboles, images) et un second doit enregistrer leur traitement.

**Critère d'acceptation** : Claude Code lit une remarque, ouvre le symbole de sa page sans recherche, puis la passe à traitée.
