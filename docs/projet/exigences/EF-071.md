# EF-071 : Résoudre les imports et appels TypeScript

**Énoncé** : Les imports relatifs sont résolus vers les fichiers du projet ; les appels directs, `this.f()` et `module.f()` sur un import deviennent des arêtes certaines ; les appels de méthode à nom unique des arêtes probables.

**Critère d'acceptation** : Sur la fixture, `impact` d'une fonction importée liste ses appelants dans un autre fichier.
