# EF-001 : Construire l'index d'un projet Rust

**Énoncé** : `wikik index` analyse tous les fichiers `.rs` du projet et enregistre dans `.wikik/` les symboles, signatures, blocs de doc, balises, hash et arêtes.

**Critère d'acceptation** : Sur la fixture Rust et sur ATS, l'index contient chaque fonction, type et méthode attendus.
