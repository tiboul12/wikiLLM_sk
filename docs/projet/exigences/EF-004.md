# EF-004 : Lire une configuration de projet optionnelle

**Énoncé** : `wikik.toml` à la racine règle les langages, chemins exclus et sévérités du check ; sans fichier, des valeurs par défaut s'appliquent.

**Critère d'acceptation** : Un chemin exclu dans `wikik.toml` n'apparaît pas dans l'index ; sans `wikik.toml`, l'index se construit.
