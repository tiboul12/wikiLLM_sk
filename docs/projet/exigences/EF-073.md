# EF-073 : Reconnaître composants Angular et fichiers de test

**Énoncé** : Une classe décorée `@Component` est un composant ; les symboles des fichiers `*.spec.ts` et `*.test.ts` sont des tests.

**Critère d'acceptation** : Sur la fixture, le composant a le genre `composant` et les symboles du fichier de test `est_test`.
