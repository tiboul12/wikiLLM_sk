# EF-083 : Installer un hook pre-commit

**Énoncé** : `wikik init --hook` installe un hook git qui lance `wikik check` avant chaque commit, sans écraser un hook existant.

**Critère d'acceptation** : Un commit qui introduit `@req EF-999` est refusé par le hook.
