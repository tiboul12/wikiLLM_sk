# EF-030 : Fournir un skill pour l'agent

**Énoncé** : Un `SKILL.md` court indique quand et comment interroger l'outil et comment écrire un bloc, avec des procédures détaillées chargées à la demande.

**Critère d'acceptation** : Un agent qui suit le skill sur ATS interroge l'outil avant d'ouvrir un fichier source.
