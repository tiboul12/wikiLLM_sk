# EF-144 : Clarifications regroupées par sujet, sans saisie préalable

**Énoncé** : Lancer une clarification ouvre directement les pistes du LLM sur le sujet ; garder, corriger ou rejeter fait la réponse, sans conclusion à écrire ; les clarifications sont rangées par sujet dans un groupe à part, avec l'état du sujet (en cours, clarifié) ; une clarification se reprend et se supprime.

**Critère d'acceptation** : REC-024.2, 025, 032, 033, 034, 035, 040.2 traitées.
