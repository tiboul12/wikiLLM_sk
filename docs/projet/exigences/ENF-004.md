# ENF-004 : Sécurité locale

**Énoncé** : Aucune écriture par le réseau ; écoute sur `127.0.0.1` par défaut ; HTML rendu assaini ; aucune ressource chargée depuis un CDN.

**Critère d'acceptation** : Revue des routes ; une page contenant `<script>` ne l'exécute pas.
