# EF-006 : Extraire les balises des blocs de doc

**Énoncé** : Les balises `@adr`, `@req`, `@topic`, `@pitfall` des blocs sont extraites et deviennent des arêtes ou des attributs du symbole.

**Critère d'acceptation** : Un bloc portant `@req EF-001` crée une arête symbole → EF-001 visible dans `symbole` et dans `exigence`.
