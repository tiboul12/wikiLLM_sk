# EF-028 : Résoudre les références @wiki:

**Énoncé** : `wikik query ref @wiki:<chemin>::<symbole>` ou `@wiki:<page>#<ancre>` renvoie l'élément désigné.
**Critère d'acceptation** : Une référence copiée depuis le wiki se résout vers le bon symbole ou la bonne section.
