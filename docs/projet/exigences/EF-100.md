# EF-100 : Lancer le serveur de l'atelier

**Énoncé** : `wikik atelier` sert l'interface de l'atelier et une API d'écriture limitée à `docs/atelier/` et `docs/projet/`, sur la boucle locale par défaut (`--autoriser-reseau` sinon).

**Critère d'acceptation** : Le serveur refuse `0.0.0.0` sans l'option ; aucune requête ne peut écrire hors des deux dossiers.
