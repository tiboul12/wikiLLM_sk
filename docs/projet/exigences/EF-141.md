# EF-141 : Graphe des liens par catégorie, lisible et stable

**Énoncé** : Le graphe montre le code, les exigences et besoins, les décisions, les documents de projet, l'atelier, les pages de l'application et les remarques, chacun de sa couleur, avec une puce par catégorie pour l'afficher ou le masquer ; il garde la même disposition d'une ouverture à l'autre, zoome assez pour lire les zones denses, donne le titre au survol et colore les liens d'un nœud sur un appui long.

**Critère d'acceptation** : Deux ouvertures donnent le même dessin ; les puces filtrent ; survol et appui long vérifiés en headless.
