# EF-040 : Servir le wiki en local

**Énoncé** : `wikik` sert le wiki sur `127.0.0.1` à partir de l'index ; ses routes de lecture n'écrivent rien (l'atelier et la réception, sections du même serveur, écrivent dans leurs seuls dossiers : ADR-0012).

**Critère d'acceptation** : Aucune route n'écrit sur le disque ; le serveur refuse d'écouter hors de la boucle locale sans option explicite.
