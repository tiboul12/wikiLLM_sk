# EF-148 : Terminal intégré et envoi du traitement

**Énoncé** : Un volet droit ouvre un terminal dans le dossier du projet ; « Traiter les remarques » y tape la consigne de traitement ; le terminal n'est ouvert qu'à la machine locale ou avec la clé affichée au lancement (ADR-0013).

**Critère d'acceptation** : REC-022 et REC-041 traitées ; sans clé, une machine du réseau n'ouvre pas de terminal.
