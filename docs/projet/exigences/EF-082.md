# EF-082 : Générer la CI et les validateurs

**Énoncé** : `wikik init --ci` écrit un workflow GitHub (check sur chaque PR, export publié sur GitHub Pages depuis la branche principale) et, si `wikik.toml` désigne des validateurs, un fichier `CODEOWNERS` pour `docs/projet/majeures/`.

**Critère d'acceptation** : Les fichiers générés existent, ne sont pas réécrits au second lancement, et `CODEOWNERS` contient les validateurs configurés.
