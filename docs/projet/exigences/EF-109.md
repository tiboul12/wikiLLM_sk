# EF-109 : Relier le wiki et l'atelier

**Énoncé** : Le wiki propose « ouvrir dans l'atelier » sur un besoin, une exigence ou un artefact ; l'atelier propose « voir dans le wiki ».

**Critère d'acceptation** : Les deux liens mènent à la bonne page.
