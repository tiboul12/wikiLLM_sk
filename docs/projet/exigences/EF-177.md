# EF-177 : Accueil et parcours de l'atelier

**Énoncé** : Le Design thinking s'ouvre sur un accueil (ateliers, création) ; le mode express ou complet se choisit pour tout l'atelier et, en express, on coche les techniques à faire ; nom et métadonnées se modifient aussi sur téléphone.

**Critère d'acceptation** : REC-091, 093, 094 traitées.
