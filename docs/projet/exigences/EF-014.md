# EF-014 : Produire une sortie texte et JSON avec code de retour

**Énoncé** : `wikik check` affiche un rapport lisible par défaut, un rapport JSON avec `--format json`, et sort avec un code non nul s'il y a au moins une erreur.

**Critère d'acceptation** : Le JSON se valide contre son schéma ; le code de retour vaut 1 en présence d'une erreur, 0 sinon.
