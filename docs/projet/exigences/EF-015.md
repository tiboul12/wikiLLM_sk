# EF-015 : Marquer un bloc comme relu

**Énoncé** : Un humain peut indiquer qu'un bloc reste valide malgré un changement de code, sans réécrire le bloc (mécanisme : SPEC-04).
**Critère d'acceptation** : Après marquage, le symbole n'est plus signalé périmé jusqu'au prochain changement de code.
