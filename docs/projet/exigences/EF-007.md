# EF-007 : Repérer les composants Leptos utilisés dans `view!`

**Énoncé** : Les balises `<Composant>` d'une macro `view!` qui désignent un composant du projet créent une arête « rend » de niveau probable.

**Critère d'acceptation** : Sur ATS, les composants rendus par `App` apparaissent comme appelés dans `impact`.
