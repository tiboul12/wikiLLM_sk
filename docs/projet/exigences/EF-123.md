# EF-123 : Déposer une remarque sur une page

**Énoncé** : Le système doit permettre de déposer sur une page une remarque (texte, genre, gravité) accompagnée d'images collées depuis le presse-papiers ; une remarque est un fichier `REC-xxx` du dépôt qui cite sa page et les symboles de son code.

**Critère d'acceptation** : Une remarque avec deux captures collées est enregistrée en un fichier et deux images, et s'affiche sous sa page.
