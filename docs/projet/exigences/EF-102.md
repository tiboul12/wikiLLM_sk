# EF-102 : Décrire chaque technique par une fiche

**Énoncé** : Chaque technique est une fiche déclarative (entrées, sorties, schéma JSON, consignes, réglages Express et Complet) chargée par le moteur ; le méga-prompt n'est plus utilisé.

**Critère d'acceptation** : Les 11 fiches se chargent et chacune valide son exemple « MyRandonnée ».
