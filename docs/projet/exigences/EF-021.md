# EF-021 : Requête fichier

**Énoncé** : `wikik query fichier <chemin>` renvoie le bloc d'en-tête, la liste des symboles avec leur rôle en une ligne, les imports et la part de code non analysée (macros).
**Critère d'acceptation** : La sortie liste tous les symboles du fichier, sans leur code.
