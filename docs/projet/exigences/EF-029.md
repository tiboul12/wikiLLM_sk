# EF-029 : Mettre l'index à jour avant de répondre

**Énoncé** : Si l'index est absent ou en retard sur les fichiers, toute requête le met d'abord à jour de façon incrémentale.

**Critère d'acceptation** : Modifier un fichier puis lancer `query symbole` montre l'état modifié sans lancer `index` à la main.
