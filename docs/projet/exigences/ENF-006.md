# ENF-006 : Robustesse aux erreurs de parse

**Énoncé** : Un fichier qui ne se parse pas entièrement est indexé partiellement et signalé, sans bloquer l'index ni les requêtes.

**Critère d'acceptation** : Une fixture contenant une erreur de syntaxe s'indexe et produit un avertissement.
