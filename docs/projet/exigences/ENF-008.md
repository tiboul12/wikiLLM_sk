# ENF-008 : Isolement du LLM

**Énoncé** : Le LLM n'a accès qu'aux outils de wikik en lecture et à la réponse structurée ; il n'écrit jamais lui-même ; seul l'atelier écrit, après choix de Tibo.

**Critère d'acceptation** : La commande de fournisseur désactive tous les outils intégrés (`--tools ""`) ; test : une demande de lecture de fichier est refusée.
