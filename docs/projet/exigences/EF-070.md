# EF-070 : Extraire les symboles TypeScript

**Énoncé** : `wikik index` lit les fichiers `.ts`, `.tsx`, `.mts`, `.cts` (hors `.d.ts`) : fonctions, classes, méthodes, champs, interfaces, types, énumérations, constantes, espaces de noms, avec leur JSDoc et leurs balises.

**Critère d'acceptation** : Sur la fixture TypeScript, chaque déclaration attendue est indexée avec son identifiant, son genre, sa visibilité et son résumé.
