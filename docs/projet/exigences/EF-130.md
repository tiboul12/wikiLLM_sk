# EF-130 : Un seul serveur, lancé par wikik

**Énoncé** : La commande `wikik`, sans sous-commande, doit lancer un serveur unique qui sert le wiki, l'atelier et le cahier de réception sur un seul port ; les sous-commandes `serve`, `atelier` et `reception` ne doivent plus exister. Lancer le serveur ne doit rien écrire dans le dépôt.

**Critère d'acceptation** : `wikik` répond sur un port avec les quatre sections ; `wikik serve` est refusé ; aucun fichier de `docs/` n'apparaît au lancement.
