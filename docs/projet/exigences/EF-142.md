# EF-142 : Récapitulatifs qui mènent aux éléments

**Énoncé** : L'accueil Produit donne un tableau des fichiers (symboles, documentés, sans doc, périmés, erreurs) ; une page de fichier résume en tête ce qui n'est pas conforme ; les ancres et les liens d'appels restent dans le cadre ; le chiffre « à relire » mène à la liste complète avec le statut de chaque document.

**Critère d'acceptation** : REC-007, 012, 013, 020, 021, 023 traitées.
