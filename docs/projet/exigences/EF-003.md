# EF-003 : Produire un dump JSON déterministe de l'index

**Énoncé** : `wikik index --dump-json` écrit l'index sous forme de JSON trié, sans horodatage.

**Critère d'acceptation** : Deux exécutions sur le même commit produisent des fichiers identiques octet pour octet.
