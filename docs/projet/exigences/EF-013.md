# EF-013 : Signaler les exigences non couvertes

**Énoncé** : `wikik check` avertit pour chaque exigence `must` au statut validé ou implémenté qu'aucun symbole ni test ne cite.
**Critère d'acceptation** : Une exigence `must` validée sans `@req` produit un avertissement.
