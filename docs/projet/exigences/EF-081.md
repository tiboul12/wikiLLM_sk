# EF-081 : Annoter les PR avec les diagnostics

**Énoncé** : `wikik check --format github` écrit les diagnostics au format des annotations GitHub Actions (`::error file=…,line=…::message`).

**Critère d'acceptation** : Une erreur `ref-req` produit une ligne `::error file=…,line=…::…`.
