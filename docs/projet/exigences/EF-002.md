# EF-002 : Mettre à jour l'index de façon incrémentale

**Énoncé** : Seuls les fichiers dont le contenu a changé depuis la dernière indexation sont ré-analysés ; les fichiers supprimés disparaissent de l'index.
**Critère d'acceptation** : Après modification d'un seul fichier, un seul fichier est ré-analysé (compteur affiché) et l'index est identique à une reconstruction complète.
