# EF-080 : Exporter le wiki en site statique

**Énoncé** : `wikik export <dossier>` écrit un site autonome (front + données JSON) lisible sans serveur wikik, sur n'importe quel chemin d'hébergement.

**Critère d'acceptation** : Sur wikiK, le dossier exporté ouvert dans un navigateur affiche l'accueil, une page fichier, une page document, la recherche et le graphe.
