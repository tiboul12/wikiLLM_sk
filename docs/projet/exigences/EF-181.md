# EF-181 : Une seule interface de réception

**Énoncé** : La carte d'une page et le Traitement affichent une remarque avec le même composant ; ses états (ouverte, traitée, validée) se lisent et se changent sur un curseur ; la couleur de la version qui contient la correction est visible ; sur téléphone, le bouton capture reprend l'image du presse-papier.

**Critère d'acceptation** : REC-082, 085, 086, 092 traitées.
