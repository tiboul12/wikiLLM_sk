# EF-160 : Cascade besoin, cahier des charges, exigence, test, ticket

**Énoncé** : Le volet Projet montre la cascade : chaque besoin, ses exigences (via le cahier des charges), chaque exigence ses tests ; un test (TEST-xxx) décrit comment vérifier l'exigence et porte son ticket de validation (à valider, validé par l'utilisateur, validé par le modèle, en échec) ; `wikik nouveau test` crée un test ; `wikik check` signale une exigence sans test.

**Critère d'acceptation** : REC-055 traitée.
