# EF-127 : Modifier et supprimer une remarque, avec son historique

**Énoncé** : Modifier une remarque doit créer une nouvelle version numérotée (`REC-001` → `REC-001.2`) qui remplace la précédente, gardée et liée (`remplace`, `remplace_par`) ; supprimer une remarque doit retirer toute sa chaîne de versions et ses images non partagées, après confirmation.

**Critère d'acceptation** : Après deux modifications, `REC-001.3` est la seule version ouverte, l'historique `REC-001 → REC-001.2 → REC-001.3` s'affiche et le wiki relie les trois ; après suppression, aucun fichier de la chaîne ni image ne reste.
