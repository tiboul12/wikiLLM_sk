# EF-153 : Graphe chargé une fois, rafraîchi, cherchable, avec les liens entre fichiers et entre pages

**Énoncé** : Le graphe global est chargé une fois par session et gardé ; un bouton le recharge ; un champ localise un nœud et zoome dessus ; les appels entre fichiers de code et les liens entre pages de l'application sont des arêtes ; un clic ouvre l'élément dans un onglet.

**Critère d'acceptation** : REC-044, 045, 068, 070 traitées.
