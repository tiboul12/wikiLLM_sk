# ENF-001 : Budget de tokens des requêtes

**Énoncé** : Les sorties respectent un budget : `carte` ≤ 4 000 tokens pour un projet de 50 000 lignes, `fichier` ≤ 1 500, `symbole` ≤ 800 sans code, `impact` ≤ 1 500. Chaque sortie peut afficher son coût estimé.

**Critère d'acceptation** : Mesuré sur ATS et wikiK en Phase 7.
