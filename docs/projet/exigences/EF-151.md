# EF-151 : Onglets de pages, détachables

**Énoncé** : Chaque page ouverte prend un onglet au-dessus du contenu ; un onglet se ferme, se réordonne et se détache dans une fenêtre du navigateur ; Ctrl+clic ou clic du milieu ouvre un lien dans un nouvel onglet ; les onglets survivent au rechargement.

**Critère d'acceptation** : REC-068, 069 traitées.
