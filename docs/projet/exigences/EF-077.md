# EF-077 : Indexer les composants Svelte

**Énoncé** : Un fichier `.svelte` est un symbole `composant` (doc : `<!-- @component -->`, sinon les commentaires de tête du script) ; son script est extrait comme du TypeScript avec ses numéros de ligne réels ; ses balises `<Composant>` créent des arêtes « rend ».

**Critère d'acceptation** : Sur la fixture, `Page.svelte` rend `Vue.svelte` (arête certaine) et la fonction du script de `Vue.svelte` a sa ligne réelle.
