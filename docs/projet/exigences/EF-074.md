# EF-074 : Accepter les balises JSDoc natives

**Énoncé** : `@param`, `@returns`, `@throws`, `@example`, `@deprecated`, `@see` et les autres balises JSDoc courantes ne sont pas signalées comme inconnues.

**Critère d'acceptation** : Un bloc JSDoc avec `@param` ne produit aucun diagnostic `balise-inconnue`.
