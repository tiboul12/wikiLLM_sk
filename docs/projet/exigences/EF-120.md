# EF-120 : Construire la carte des pages à partir du code

**Énoncé** : Le système doit construire la liste des pages d'une application à partir de son code, sans configuration : routes déclarées (Angular, Vue, React Router, Leptos, SvelteKit), énumération de navigation (`enum Page`), pages HTML, composants rangés dans un dossier de pages ; chaque page porte son nom, sa route éventuelle et les symboles de son code.

**Critère d'acceptation** : Sur wikik, ATS et shelley-studio-llm, toutes les pages atteignables par l'utilisateur sont trouvées, chacune reliée à son composant.
