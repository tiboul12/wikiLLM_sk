# EF-105 : Écrire les artefacts en fichiers traçables

**Énoncé** : Chaque artefact (pitch, idée, analyse, SCAMPER, storyboard) est un fichier de `docs/atelier/` avec frontmatter et champ `sources` vers les artefacts dont il vient.

**Critère d'acceptation** : Une idée retenue en SCAMPER cite l'idée et l'axe d'origine dans `sources`.
