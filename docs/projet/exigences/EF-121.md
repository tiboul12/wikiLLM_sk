# EF-121 : Corriger la carte sans perdre les corrections

**Énoncé** : Le système doit permettre de renommer, masquer ou regrouper une page de la carte, et un nouveau scan doit ajouter les pages nouvelles sans défaire ces corrections.

**Critère d'acceptation** : Une page renommée puis masquée le reste après un nouveau scan ; une page ajoutée au code apparaît.
