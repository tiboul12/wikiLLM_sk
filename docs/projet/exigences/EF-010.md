# EF-010 : Détecter la doc périmée

**Énoncé** : `wikik check` signale chaque symbole dont le corps ou la signature a changé alors que son bloc de doc n'a pas changé (définition exacte : SPEC-04).
**Critère d'acceptation** : Sur la fixture, modifier le corps d'une fonction documentée sans toucher son bloc produit un diagnostic « périmé ».
