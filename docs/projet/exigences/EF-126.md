# EF-126 : Ouvrir la page reçue dans l'application

**Énoncé** : Chaque page du cahier doit offrir un lien vers la page correspondante de l'application reçue (adresse de l'application, saisie une fois, plus la route de la page) ; la route d'une page doit pouvoir être ajoutée ou corrigée.

**Critère d'acceptation** : Avec l'adresse `http://10.0.0.21:4200`, la page `/configurer` de shelley ouvre `http://10.0.0.21:4200/configurer` ; une page sans route indique comment en ajouter une.
