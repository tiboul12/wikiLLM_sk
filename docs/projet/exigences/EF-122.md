# EF-122 : Compléter la carte avec le LLM

**Énoncé** : Le système doit pouvoir demander au LLM (CLI local, branché sur wikik par MCP) les pages que les détecteurs n'ont pas trouvées.

**Critère d'acceptation** : Sur un projet sans détecteur adapté, le LLM propose des pages reliées à des symboles existants.
