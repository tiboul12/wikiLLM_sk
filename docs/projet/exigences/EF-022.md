# EF-022 : Requête symbole

**Énoncé** : `wikik query symbole <id>` renvoie le bloc complet, la signature, les appelants, les appelés (avec niveau certain / probable), les ADR et exigences liés et le statut de la doc ; le code seulement avec `--code`.

**Critère d'acceptation** : Sur la fixture, la sortie contient appelants et appelés attendus et le statut « à jour » ou « périmé ».
