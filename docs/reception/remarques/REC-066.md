# REC-066 : quand je me connecte à mon terminal il faut qu'il s'ouvre directement sur mon do…

quand je me connecte à mon terminal il faut qu'il s'ouvre directement sur mon dossier du projet

## Traitement

**traitee** : Le terminal reçoit le dossier du projet en chemin absolu (et PWD), il s'ouvre donc toujours dans le projet même si wikik a été lancé avec une racine relative.
