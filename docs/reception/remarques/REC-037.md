# REC-037 : quand on séléction un élément il faut ouvrir son accordéon et le centrer

quand on séléction un élément il faut ouvrir son accordéon et le centrer

![capture 1](../images/REC-037-1.png)

## Traitement

**traitee** : L'élément de la page ouverte est déplié (accordéons parents) et centré dans le panneau ; le panneau n'est plus recréé à chaque page, les accordéons gardent leur état.
