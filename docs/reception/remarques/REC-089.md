# REC-089 : quand je ferme les onglet le dérnière onglet ouvert n'affiche pas sont contenu m…

quand je ferme les onglet le dérnière onglet ouvert n'affiche pas sont contenu mais celui du précédent

![capture 1](../images/REC-089-1.png)

## Traitement

**traitee** : Fermer l'onglet actif (y compris le dernier à droite) charge la page de l'onglet qui devient actif, au lieu de laisser le contenu de l'onglet fermé.
