## ⚡ Principes Directeurs
- **Zéro Dépendance Pip** : Uniquement basé sur la bibliothèque standard Python 3.
- **Docs-as-Code** : Markdown pur versionné avec Git, synchronisation continue code/doc.
- **Réseau & Multi-projets** : Serveur local partageable sur le réseau local pour navigation sur mobile, tablette ou poste distant.
