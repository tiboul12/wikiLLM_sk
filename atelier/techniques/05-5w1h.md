# 5W1H

## Rôle

Approfondir les idées retenues avec les six questions de Kipling : quoi, qui, où, quand, pourquoi, comment. Le LLM pré-remplit, Tibo corrige.

## Consignes

### questions

Lis l'idée indiquée et ses sources (outil document). Réponds aux six questions de la méthode Kipling pour cette idée, deux à quatre phrases chacune, en t'appuyant sur le pitch et les artefacts de l'atelier ; écris « à préciser » quand l'information manque.

## Règles

- Une analyse par idée sélectionnée.

## Exemple

Projet « MyRandonnée » (exemple du framework d'origine) : réponses attendues par sous-étape, utilisées par le fournisseur factice et les tests.

```json
{
  "questions": [
    {
      "quoi": "Une alerte quand la visibilité chute sur l'itinéraire.",
      "qui": "Le randonneur en cours de sortie.",
      "ou": "En montagne, souvent hors réseau.",
      "quand": "Pendant la sortie, avant que le brouillard n'arrive.",
      "pourquoi": "Éviter de se perdre.",
      "comment": "Prévision locale téléchargée avant le départ et position GPS."
    }
  ]
}
```
