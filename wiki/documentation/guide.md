## 🚀 Démarrage Rapide en 3 Étapes

### 1. Lancer le serveur
Depuis le répertoire du projet, lancez :
```bash
python3 serveur.py
```
Le serveur s'exécute immédiatement sans aucune dépendance `pip`.

### 2. Accéder à l'interface
Ouvrez votre navigateur sur **[http://localhost:8000](http://localhost:8000)** (ou via l'adresse IP réseau affichée pour un accès mobile/tablette).

### 3. Éditer et interconnecter les notes
- Utilisez `Ctrl+S` dans l'éditeur pour sauvegarder.
- Créez des liens entre vos notes grâce à la syntaxe `[[NomNote]]` ou `[[dossier/NomNote|Libellé]]`.
- Basculez sur l'onglet **🕸️ Graphe** pour visualiser l'ensemble des interconnexions.
